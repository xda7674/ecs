**轻量应用服务器能按小时付费吗？**

**香港地域建站真的不用备案吗？**

最常见的原因是密码。新创建的轻量应用服务器没有初始密码，先在控制台重置密码再登录；控制台还提供自助诊断工具，远程连接异常时可以先跑一遍。
